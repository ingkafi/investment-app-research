# Investment App Research

Repository for research and documentation on investment platforms, asset classes, and market infrastructure.

## Contents

- `indonesian-investment-platforms.md` — Comprehensive research on trading and investment platforms accessible to Indonesian residents, organized by asset class (equities, forex, crypto, mutual funds, bonds, commodities, P2P).
- `basic-of-trading.md` — Practical primer on trading mechanics, order types, timeframes, and technical analysis fundamentals.
- `quantitative-asset-scoring-metric.md` — Quantitative scoring framework for 28 individual assets (forex, crypto, US/Indonesian stocks, commodities) across predictability, effort, and speed dimensions.

## Status

This is a living document. Verify current regulatory status and fees directly with platforms and regulators (OJK, BAPPEBTI, BEI) before opening accounts.
